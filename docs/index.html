시간표

파랑은 수업, 초록은 개인 일정, 빨강은 공지에서 찾은 일정이에요. 일정을 누르면 고치거나 지울 수 있고, 시간이 없는 일정은 맨 위 줄에 나와요.

학점 계산기

에브리타임과 같은 방식(4.5 만점)으로 평점을 계산하고, 졸업까지 남은 학점을 알려 줘요

과목 · 성적

성적을 고르면 계산에 들어가요. P(패스)는 학점만 취득하고 평점에는 안 들어가요. F·NP는 학점을 얻지 못해요. 구분(전공·교양 등)은 직접 바꿀 수 있어요.

졸업 요건 2023학번 기준

※ 총 130학점 · 교양 40(기초 17 + 핵심 23)은 신한대 졸업심사기준 표 기준이에요. 전공 50과 마이크로디그리 30은 표의 열이 불분명해서 확인 필요(학과 내규 40~50)예요. 숫자를 눌러 고치면 바로 계산돼요. 부족하지 않으면 남는 전공·교양은 일반선택으로 쳐요.

졸업 인증 체크

목표 평점 계산 졸업 때 평점

을 목표로 하면

평점 = Σ(학점 × 점수) ÷ Σ(학점). A+ 4.5 · A0 4.0 · B+ 3.5 · B0 3.0 · C+ 2.5 · C0 2.0 · D+ 1.5 · D0 1.0 · F 0. 근거: 졸업심사기준 · 2023학번 졸업조건

내 PC AI (Ollama)
            

            

              ① ollama.com/download에서 Windows용을 설치해요. (명령으로는 winget install Ollama.Ollama)

              ② 명령 프롬프트에서 모델을 받아요. 그래픽카드가 없는 보통 PC에는 작은 모델이 알맞아요.

              ollama pull qwen2.5:3b (빠름, 약 2GB) 또는 ollama pull qwen2.5:7b (더 똑똑하지만 느림)

              ollama pull gemma3:4b (사진 · 그림 문제를 볼 때)

              ③ 확장 프로그램이 설치돼 있으면 별도 설정 없이 연결돼요. 확장 없이 쓰려면 Ollama를 OLLAMA_ORIGINS=* 설정으로 켜야 해요.

              내 PC 안에서만 계산하고 인터넷으로 내용이 나가지 않아요. 작은 모델은 틀릴 수 있으니 결과를 꼭 확인해 주세요.
