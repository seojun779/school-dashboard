# 나의 학교 — 과제 · 시간표 · 공부 도우미

신한대 학생을 위한 개인용 학교 생활 대시보드예요. **내 브라우저와 내 PC 안에서만** 동작하고, 학교 비밀번호는 어디에도 입력하지 않아요.

## 무엇을 해 주나요

| 기능 | 내용 |
|---|---|
| 오늘 · 캘린더 | 지금 · 다음 일정, 가장 급한 마감, 이번 달 전체 일정 캘린더 |
| 과제 · 출석 | 사이버캠퍼스의 과제 마감(시각까지), 제출 여부, 온라인출석, 공지 속 일정 자동 추출 |
| 마감 알림 | 마감 24시간 · 6시간 · 1시간 전에 크롬 알림 (확장 프로그램) |
| 시간표 · 학점 계산기 | 에브리타임 시간표 가져오기, 4.5 만점 평점 계산, 졸업 요건 진행 |
| 드라이브 | 사이버캠퍼스 자료 + 내가 올린 자료(PDF · PPTX · DOCX · HWPX · TXT) 한곳에서 검색 |
| 공부 도우미 | 강의자료 → Claude 대화 → 외부 자료 순서로 근거를 밝히며 답하고, 연습문제를 만들어요 |
| AI 작업실 | 내 PC의 AI(Ollama)로 문제 풀이 · PPT 제작 · 시각화 · 캔버스 (Claude 사용량 0) |

## 시작하기 (3단계)

1. **확장 프로그램 설치** — `나의학교_확장프로그램.zip`을 받아 압축을 풀고, 크롬에서 `chrome://extensions` → 개발자 모드 → **압축해제된 확장 프로그램을 로드합니다**로 그 폴더를 선택해요.
2. **사이트 열기** — https://seojun779.github.io/school-dashboard/ 를 열어요. (직접 만든 경우 `docs/index.html`)
3. **로그인** — 사이트가 사이버캠퍼스 로그인 화면을 열면 직접 로그인해요. 로그인이 끝나면 자동으로 돌아와서 자료를 읽어요.

## 내 PC AI 연결 (선택)

AI 작업실과 "내 PC AI로 쉽게 설명" 버튼은 [Ollama](https://ollama.com/download)가 필요해요.

```
ollama pull qwen2.5:7b     # 글 · 문제 풀이 (보통 PC에는 qwen2.5:3b가 더 빨라요)
ollama pull gemma3:4b      # 사진 문제를 볼 때
```

확장 프로그램이 설치돼 있으면 따로 설정할 것이 없어요. 작은 모델은 틀릴 수 있으니 중요한 내용은 강의자료로 확인해 주세요.

## 개인정보

- 학교 계정 정보는 입력받거나 저장하지 않아요. 로그인은 학교 · 에브리타임 · Claude 화면에서 직접 해요.
- 읽은 과제 · 성적 · 대화 · 올린 파일은 **이 브라우저(IndexedDB)** 에만 저장돼요. 서버로 보내지 않아요.
- 확장 프로그램은 읽기만 하고, 제출 · 신청 · 수정은 하지 않아요.
- 에브리타임과 claude.ai의 내부 화면에 기대는 부분은 사이트가 바뀌면 깨질 수 있어요. 본인 계정의 본인 정보를 읽는 개인 용도로만 쓰세요.

## 직접 만들기

```
python 소스/build_all.py          # 사이트 · 확장 프로그램 · 북마클릿 다시 만들기
```

`소스/modules/`에 드라이브 · AI 작업실 코드가, `소스/dashboard_template.html`에 화면 원본이 있어요. 결과 파일을 직접 고치지 말고 소스를 고쳐서 다시 만드세요.

## 한계

- 공부 도우미는 자료의 문장을 골라 보여주는 방식이라 새 설명을 지어내지 않아요. 풀어 쓴 설명은 내 PC AI 버튼으로 따로 받아요.
- 스캔한 PDF와 `.hwp`(옛 한글 파일)는 글자를 읽지 못해요.
