사이버캠퍼스 보드

신한대 사이버캠퍼스에 내가 직접 로그인한 상태에서 버튼 하나로 내 과제 마감, 온라인출석부, 강의자료를 한 화면에 모아 봅니다.

안전하게 만든 방식
  • 아이디·비밀번호를 묻지도, 읽지도 않아요. 로그인은 학교 사이트에서 본인이 직접 해요.
  • 내 브라우저 안에서만 동작해요. 읽은 내용은 어디로도 전송되지 않고, 내가 고른 내 PC 폴더에만 저장돼요. (서버가 없어요)
  • 학교 사이트에서는 읽기만 해요. 과제 제출이나 설정 변경은 하지 않아요. (파일 저장은 내가 고른 폴더에만 해요)
  • 코드가 궁금하면 sh-board.js를 열어 읽어 보세요.

설치 (1분)

  1. 크롬 북마크바를 켜요 (Ctrl + Shift + B).
  2. 아래 파란 버튼을 북마크바로 끌어다 놓아요.

사이버캠퍼스 보드

끌어다 놓기가 안 되면: 새 북마크를 만들고, 이름은 사이버캠퍼스 보드, 주소(URL)에는 아래 코드를 통째로 붙여 넣어요.

사용법

  1. 신한대 사이버캠퍼스를 열고 직접 로그인해요.
  2. 북마크바의 사이버캠퍼스 보드를 눌러요. 잠시 뒤 과제 · 온라인출석부 · 강의자료 · 내 사이트 업데이트 탭이 나와요. (이 팝업은 간단히 훑어보는 용도예요.)
  3. 내 사이트 업데이트 탭에서 사이트 폴더 선택하기를 눌러요. 내려받은 폴더 중 과제표.html이 들어 있는 폴더를 골라요. 크롬이 "파일 변경 허용"을 물으면 허용해 주세요.
  4. 내 과제·출석·강의자료 목록이 그 폴더의 내데이터.js에 저장돼요.
  5. 폴더의 대시보드.html을 열면 시간표·과제·출석·강의자료·공부 도우미가 한 화면에 나와요.
  6. 다음부터는 사이버캠퍼스에 로그인하고 북마크를 눌러 "마지막 폴더로 바로 업데이트" 버튼을 누르면 돼요. 폴더를 다시 고를 필요가 없어요.

대시보드에서 바로 로그인하기

  1. 대시보드.html을 열면 로그인이 필요할 때 "사이버캠퍼스 로그인이 필요해요" 창이 떠요.
  2. 로그인 창 열기를 누르고, 새 창에서 학교 아이디로 직접 로그인해요.
  3. 로그인 후 그 창에서 북마크 사이버캠퍼스 보드를 누르고 대시보드로 보내고 이 창 닫기를 눌러요.
  4. 창이 닫히면서 대시보드가 최신 데이터로 새로고침돼요. (폴더를 고를 필요가 없어요)

학교 사이트가 로그인 뒤에 내 PC의 파일로 자동으로 돌아오게 할 수는 없어서, 이렇게 창을 열어 데이터를 전달하는 방식이에요. 비밀번호는 대시보드에 입력하지 않아요.

무엇을 읽어 와요?

  • 과제: 모든 강의의 과제와 제출 여부, 마감, 안내 파일
  • 온라인출석부: 주차별 출석·지각·결석
  • 학습활동: 강의자료(파일·폴더), URL 링크, 게시판 글(과목공지·질의응답)과 첨부파일
  • 공지 속 일정: 게시글에서 "11월 23일 마감", "12/10 보강"처럼 날짜가 적힌 문장을 찾아 시간표와 과제표에 "공지에서 찾음 · 확인 필요"로 넣어요. 문장에서 읽는 거라 틀릴 수 있어서 원문 링크를 함께 보여 줘요.

새 공지 첨부파일 받기 (선택)

  1. 내 사이트 업데이트 탭에서 폴더를 고르면, 내 폴더에 없는 새 공지 첨부파일과 강의실 자료가 목록으로 나와요.
  2. 받을 파일에 체크하고 내려받아 폴더에 넣기를 누르면 첨부파일/과목명/ 폴더에 저장돼요. 80MB 이상 파일과 다른 언어 번역본은 기본으로 선택되지 않아요.
  3. 강의자료 화면에서 받은 파일은 "내 폴더에 있음"으로 바뀌고 바로 열려요.

선택한 폴더 밖은 건드리지 않고, 같은 이름의 파일을 덮어쓰지 않아요. 폴더는 크롬·엣지에서만 고를 수 있어요.

알아 둘 점

  • 학교 사이트 화면 구조가 바뀌면 일부가 안 보일 수 있어요. 이상하면 학교 사이트에서 직접 확인해 주세요.
  • 학교 정책에 따라 자동 조회를 제한할 수 있어요. 내 계정으로 내 정보만 읽는 용도로만 써 주세요.
  • 친구에게 줄 때는 친구용_배포 폴더(또는 zip)를 통째로 전달하면 돼요. 내 데이터는 들어 있지 않고, 각자 로그인해서 자기 데이터를 저장해요. 비밀번호는 어디에도 필요 없어요.
