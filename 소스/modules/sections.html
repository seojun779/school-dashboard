내 PC AI (Ollama)
            

            

              ① ollama.com/download에서 Windows용을 설치해요. (명령으로는 winget install Ollama.Ollama)

              ② 명령 프롬프트에서 모델을 받아요. 그래픽카드가 없는 보통 PC에는 작은 모델이 알맞아요.

              ollama pull qwen2.5:3b (빠름, 약 2GB) 또는 ollama pull qwen2.5:7b (더 똑똑하지만 느림)

              ollama pull gemma3:4b (사진 · 그림 문제를 볼 때)

              ③ 확장 프로그램이 설치돼 있으면 별도 설정 없이 연결돼요. 확장 없이 쓰려면 Ollama를 OLLAMA_ORIGINS=* 설정으로 켜야 해요.

              내 PC 안에서만 계산하고 인터넷으로 내용이 나가지 않아요. 작은 모델은 틀릴 수 있으니 결과를 꼭 확인해 주세요.
            

          
답을 찾는 방법
            

              
              
              
            

            
📌 답변 기준 ① 강의자료 → ② 이전 Claude 대화(Claude가 분석한 강의 내용) → ③ 강의자료 밖 외부 자료(별도 표시). 자료에 없는 내용은 추측하지 않고, 다른 근거를 쓰면 그렇다고 표시해요.

          
Claude 대화 학습시키기 (클로드로 받은 설명이나 자료를 여기에 학습)
            

              
① Claude에서 받은 답을 붙여넣거나 ② claude.ai의 "데이터 내보내기"로 받은 conversations.json(또는 .txt/.md)을 선택해 주세요. 이 기기에만 저장돼요.
